# LED's'Zeppelin

Ein Sideways-Shoot'em'up im Pixel-Look: Du steuerst einen Zeppelin über eine nächtliche Stadt, schießt Gegner ab und wirfst LEDs auf die dunklen Häuser, damit sie wieder leuchten. Dazu gibt's 70er-Rock, live im Browser erzeugt.

**Spielen:** https://dasistdaniel.github.io/led-s-zeppelin/ oder `index.html` lokal im Browser öffnen, keine Installation nötig.

## Steuerung

| Taste | Aktion |
|---|---|
| Pfeiltasten / WASD | fliegen |
| Leertaste (halten) | schießen |
| X | LED abwerfen |
| Links / Rechts im Titelbild | Schwierigkeit wählen |
| P / Esc | Pause (mit Weiter / Beenden) |
| M | Ton an/aus |

**Handy/Tablet (quer halten):** links ziehen = fliegen, rechts tippen = schießen, LED-Knopf = LED abwerfen, II oben rechts = Pause.

## Features

- Drei Schwierigkeitsstufen mit eigenen Highscores
- Begrenzter LED-Vorrat, der sich wieder auflädt (Normal/Schwer), plus LED-Pakete als Extra
- Gegner: Fledermäuse, Doppeldecker, Sperrballons
- Bossgegner **Stromfresser**, der die Stadt wieder ausknipst
- Extras: Herz, 3-fach-Schuss, LED-Paket
- Gitarrensolo ab Combo 6, das bei längeren Serien immer wilder wird
